# PRD：歌剧魅影 — 2D 点击探索游戏（完整五幕）

> **状态**：Draft  
> **日期**：2026-10-27  
> **技术栈**：React + Vite + Canvas 2D + Tone.js + Zustand  
> **平台**：桌面浏览器 + 移动端  
> **游戏时长**：40-60 分钟（5 幕合计）  
> **后续路线**：2D 验证完毕后升级为 Three.js / Unity 3D 第一人称版本

---

## 一、愿景

一款**2D 横版点击探索**浏览器游戏，以旁观者/幽灵的视角亲历《歌剧魅影》音乐剧的五个经典场景。每一幕围绕一首核心名曲展开，玩家通过**点击移动、收集线索、触发剧情**推进故事。

**核心体验**：你是一个穿越时空的隐形观众——看得见他们，他们看不见你。

**风格**：盲盒手办 Q 版美术风格（参考 Rylee 的 Phantom Blind Box 设计），暗色哥特背景 + 暖色烛光氛围。

---

## 二、技术架构

### 2.1 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 渲染 | HTML Canvas 2D | 场景绘制、角色动画、粒子效果 |
| UI | React + Tailwind | 菜单、背包、文档阅读界面 |
| 音频 | Tone.js | 自适应分层音乐、空间音效 |
| 状态 | Zustand | 玩家进度、收集品、剧情标记 |
| 构建 | Vite（现有项目） | 代码分割，按幕懒加载 |

### 2.2 升级 3D 的设计

所有逻辑与渲染分离：

```
src/phantom/
├── core/           ← 不变：剧情、收集品、音乐、状态
│   ├── store.ts
│   ├── story.ts
│   ├── music.ts
│   └── types.ts
│
├── renderer-2d/    ← 当前：Canvas 2D 渲染
│   ├── Scene2D.tsx
│   ├── Character2D.tsx
│   └── areas/
│
└── renderer-3d/    ← 将来：Three.js 3D 渲染（替换 renderer-2d）
    ├── Scene3D.tsx
    ├── Player.tsx
    └── areas/
```

升级时只替换 `renderer-2d` → `renderer-3d`，`core/` 完全复用。

### 2.3 场景渲染方案

每个区域 = **一张宽幅背景图**（AI 生成或手绘，2048×1024px） + **多层视差滚动**。

```
┌─────────────────────────────────────┐
│  远景层 (0.3x 视差) — 天花板/远处墙壁  │
│  中景层 (0.6x 视差) — 柱子/家具        │
│  近景层 (1.0x 视差) — 可交互物品        │
│  角色层 — Q 版立绘                    │
│  前景层 (1.2x 视差) — 装饰/蜡烛        │
│  UI 层 — 提示文字/交互按钮             │
└─────────────────────────────────────┘
```

### 2.4 角色方案

- **粒子剪影**为主（方案 A）：暗色烟雾（魅影）、暖金光点（克里斯汀）、冷银光点（拉乌尔）
- **面具是唯一实体道具**：白色瓷质半面具，始终清晰可见
- 角色有**预设动画帧**：站立、行走、歌唱、鞠躬、消散
- 升级 3D 时：粒子剪影 → Tripo3D 生成的 Q 版 GLB 模型

## 三、全局系统

### 3.1 交互系统

| 操作 | 桌面 | 移动端 |
|------|------|--------|
| 移动 | 点击地面某处 → 角色视角平移到该位置 | 点击 |
| 查看 | 鼠标悬停物品 → 发光提示 | 物品自动微弱发光 |
| 互动 | 点击发光物品 → 触发事件 | 点击 |
| 背包 | 点击右上角图标或按 Tab | 点击图标 |
| 暂停 | ESC 或点击暂停图标 | 点击图标 |

### 3.2 自适应音乐系统

与之前 PRD 一致，Tone.js 五层叠加：

| 层 | 乐器 | 触发条件 |
|----|------|---------|
| 1（底层） | 管风琴持续音 | 始终播放，每幕/每区域变调 |
| 2 | 弦乐 | 第 1 个收集品 |
| 3 | 竖琴 | 第 3 个收集品 |
| 4 | 合唱 | 第 5 个收集品 |
| 5 | 完整管弦乐 | 高潮事件 |

**每幕有独立的核心曲目**，在剧情关键节点以完整版本播放（见各幕详情）。

### 3.3 收集品系统

每幕 3-5 个收集品。点击发光物品 → 捡起动画（物品飞向背包图标） → 弹出全屏羊皮纸阅读界面。

全局背包：皮革日记本风格，按幕分页，记录所有已收集物品。每个物品有：名称、缩略图、来源区域、内容文本。

### 3.4 魅影氛围系统

与之前 PRD 一致，按收集品数量分 5 级：

| 等级 | 触发 | 效果 |
|------|------|------|
| 安静 | 0 件 | 背景管风琴 |
| 微动 | 1-2 件 | 灯光闪烁（canvas 亮度动画） |
| 注视 | 3-4 件 | + 耳语音效 + 玫瑰花瓣粒子 |
| 跟踪 | 5-6 件 | + 屏幕边缘暗影闪过 |
| 高潮 | 全部 | 触发该幕终场事件 |

### 3.5 存档系统

- `localStorage` 自动存档：每幕开始时保存
- 存档数据：当前幕、当前区域、已收集物品列表、剧情标记
- 主菜单可选择"继续游戏"或"从第 X 幕开始"

## 四、第一幕：Think of Me

> **核心曲目**：Think of Me  
> **场景**：歌剧院剧场（舞台 + 观众席）  
> **时长**：8-10 分钟  
> **情绪线**：好奇 → 惊叹 → 不安

### 4.1 剧情

**开场**：黑屏。一段文字缓缓出现——

> *"1881年，巴黎歌剧院。一场注定改变一切的演出即将开始。"*

画面渐亮。你站在剧场的观众席后排。舞台上正在彩排，灯光昏暗。

**第一段（彩排）**：舞台上，卡洛塔（红色光点人形，体态夸张）正在唱歌。经理们坐在前排低声交谈。突然——头顶的布景板"意外"坠落，差点砸中卡洛塔。她尖叫着跑下台。经理们慌张。

**互动**：你可以点击舞台各处探索——落下的布景板上有刀痕（线索：魅影的手段）。

**第二段（克里斯汀登场）**：混乱中，一个年轻女孩被推上舞台。灯光聚焦在她身上——克里斯汀（暖金色光点构成的人形，长裙轮廓可辨）。

**《Think of Me》响起。** 她从紧张到自信，声音越来越亮。整个剧场的灯光随着她的歌声逐渐亮起。空座位上开始出现**半透明的观众幽影**——他们被歌声"召唤"而来。

**互动**：你可以在观众席间移动。在歌曲最高潮时，抬头看向五号包厢——**一个黑色的模糊身影**正注视着舞台。

**第三段（演出结束后）**：观众幽影消散。剧场空了。克里斯汀的身影走向后台化妆间。你跟上——在化妆间门口听到镜子后面传来一个声音在轻声叫她的名字。

### 4.2 区域地图

```
┌──────────────────────────────────────────┐
│                剧场                       │
│  ┌─────────┐                             │
│  │  舞台    │  ← 彩排/演出发生处           │
│  │         │  布景板、道具、脚灯            │
│  └─────────┘                             │
│  ┌─────────────────────────────────────┐ │
│  │  观众席                              │ │
│  │  前排：经理座位    五号包厢 ↗         │ │
│  │  中排：空座位（幽影出现）              │ │
│  │  后排：你的起始位置                   │ │
│  └─────────────────────────────────────┘ │
│                    ↓                      │
│  ┌─────────────┐                         │
│  │  后台通道    │→ 化妆间门口（结尾）      │
│  └─────────────┘                         │
└──────────────────────────────────────────┘
```

### 4.3 收集品

| # | 名称 | 位置 | 内容 | 靠近效果 |
|---|------|------|------|---------|
| 1 | 被砍断的绳索 | 舞台上方（坠落布景板附近） | 绳子被利刃割断，不是自然磨损 | 绳索轻微晃动 |
| 2 | 经理的备忘录 | 前排座椅上 | "五号包厢绝不可出售——O.G." | 纸张边角微微翘起 |
| 3 | 魅影的纸条 | 五号包厢椅背后 | "她已经准备好了。"——笔迹优雅但力道极重 | 包厢内烛光闪烁 |

### 4.4 技术实现

**场景渲染**：
- 背景：AI 生成的歌剧院剧场内景（暗红色调，金色装饰，水晶灯）
- 舞台灯光：canvas `radialGradient`，跟随克里斯汀位置移动
- 布景板坠落：sprite 动画（3 帧，0.5 秒）+ 屏幕抖动（`translate` 偏移 + 衰减）
- 幽影观众：30-50 个半透明灰色椭圆 + 头部圆形，`globalAlpha` 从 0 渐变到 0.15

**音乐**：
- 彩排段：管风琴底层 + 远处嘈杂人声环境音
- 布景坠落：突然静音 0.3 秒 → 碰撞音效
- 《Think of Me》：预录或 Tone.js 合成的旋律，分 4 段渐进
  - 段 1（紧张）：单钢琴，tempo 慢
  - 段 2（成长）：加入弦乐
  - 段 3（绽放）：加入竖琴 + 合唱
  - 段 4（高潮）：完整管弦乐，灯光全亮
- 结尾：音乐渐弱，只剩回声。镜后的声音用低通滤波 + 混响处理

**角色动画**：
- 卡洛塔：红色粒子，夸张手势（手臂摆动大），逃跑时粒子散乱
- 克里斯汀：金色粒子，由松散逐渐收紧（从紧张到自信）
- 魅影：黑色剪影，只在五号包厢闪现 0.5 秒
- 经理们：灰色小粒子团，在前排来回移动

## 五、第二幕：The Phantom of the Opera

> **核心曲目**：The Phantom of the Opera  
> **场景**：化妆间 → 镜子 → 地下隧道 → 地下湖  
> **时长**：10-12 分钟  
> **情绪线**：神秘 → 敬畏 → 沉浸

### 5.1 剧情

**开场**：你在克里斯汀的化妆间。桌上摆满鲜花和贺卡。镜子前的蜡烛投下跳动的影子。

**互动**：你可以点击查看桌上的物品——拉乌尔送的花束（附贺卡）、其他演员的道具、一面古老的全身镜。

**第一段（镜子打开）**：当你点击镜子时——镜面开始发光，表面泛起涟漪。一只戴白手套的手从镜中伸出。克里斯汀的光点人形被牵引着走向镜子。

**《The Phantom of the Opera》二重唱响起。**

镜子变成了一扇门。你跟着他们进入。

**第二段（地下隧道）**：镜子后面是一条向下的螺旋石梯。蜡烛沿着墙壁**一根根自动点燃**，像在为你引路。隧道越来越深，空气越来越湿冷。铁栅栏、拱门、滴水声。

**互动**：你可以在墙壁上发现魅影的涂鸦——五线谱和音符。

**第三段（地下湖）**：隧道尽头，一片开阔的地下湖。水面平静如镜。一条小船停在岸边。**数百根蜡烛从水面升起**——这是音乐剧中最经典的画面。

你的视角随着船自动移动，穿过烛光倒影的水面。克里斯汀和魅影的身影在船头——他披着斗篷，她回头望着来时的路。二重唱在洞穴中回荡。

**结束**：船靠岸。远处是一扇微微发光的拱门——魅影的密室。

### 5.2 区域地图

```
化妆间 → [镜子传送] → 螺旋石梯 → 地下隧道 → 地下湖（自动船段）→ 湖岸（密室入口）
```

4 个场景依次推进，不可回头。

### 5.3 收集品

| # | 名称 | 位置 | 内容 |
|---|------|------|------|
| 1 | 拉乌尔的贺卡 | 化妆间桌上 | "今晚你是最闪耀的星——你的老朋友 R" |
| 2 | 墙上的乐谱涂鸦 | 地下隧道墙壁 | 一段未完成的旋律，笔迹与魅影纸条一致 |
| 3 | 蜡烛台上的刻字 | 地下湖岸边 | 一个心形图案里刻着 "C" |

### 5.4 技术实现

**镜子传送效果**：
- 镜面涟漪：canvas 正弦波扭曲（对背景采样 + `sin` 偏移 + 渐进振幅）
- 过渡动画：镜面向外扩展 → 白光填满屏幕 → 渐变到新场景
- 时长：2 秒

**蜡烛逐一点燃**：
- 预设 20-30 个蜡烛位置
- 按照玩家推进方向依次触发：每根蜡烛 `opacity` 从 0 → 1（0.3 秒）+ 微火焰粒子（3-5 个橙黄色粒子向上漂浮）
- 点燃间隔：0.15 秒
- 点燃时伴随轻微 "嘶" 音效

**地下湖**：
- 背景：深蓝黑色 + 水面反射线（水平正弦波动的浅色线条）
- 蜡烛倒影：每根蜡烛在水面下有一个 `scaleY(-1)` + `globalAlpha 0.3` 的镜像
- 船移动：自动横向滚动，速度缓慢（每秒 30px），背景视差
- 雾气：底部渐变白色 + 随机低透明度圆形粒子漂浮

**音乐**：
- 化妆间：安静的环境音（远处掌声回声、脚步声）
- 镜子打开时：低频嗡鸣 → 管风琴单音渐强
- 《The Phantom of the Opera》：随船移动播放完整版。二重唱用合成器模拟（低音：FM 合成器深沉旋律；高音：AM 合成器明亮旋律）
- 地下湖环境：水滴回声（`delay` 效果器 + 长 `reverb`）

## 六、第三幕：Music of the Night

> **核心曲目**：Music of the Night  
> **场景**：魅影的密室  
> **时长**：8-10 分钟  
> **情绪线**：迷醉 → 震撼 → 心碎

### 6.1 剧情

**开场**：你走进魅影的密室。这是一个洞穴改造的房间——到处是蜡烛、成堆的乐谱、墙上挂着克里斯汀的画像。中央摆着一架巨大的管风琴。角落里有一个穿婚纱的人形模型（蜡像）。

**第一段（演奏）**：魅影的暗色剪影坐在管风琴前。**《Music of the Night》响起。** 他开始弹奏。随着曲子推进，蜡烛一根根亮起，像波浪一样从管风琴向四周扩散。墙壁上的影子开始跳舞——像是音乐本身有了生命。

**互动**：你可以在密室内自由点击探索。管风琴上的琴键会随音乐发光。点击乐谱架上的手稿可以看到《唐璜的胜利》的片段。

**第二段（揭面）**：曲子来到最温柔的部分。克里斯汀的光点人形缓缓走向魅影，伸手触碰他的脸——

**她摘下了面具。**

一瞬间：

- 音乐骤停
- 所有蜡烛同时熄灭
- 完全黑暗，持续 1.5 秒
- 一声愤怒的吼叫
- 蜡烛重新亮起，但光线变成冷色调

魅影转过身——你**第一次看到他的脸**。半边扭曲，用光影和粒子表现（不做写实恐怖，而是悲伤的笔触：粒子稀疏、颜色冷淡、形状不对称）。他愤怒地推开克里斯汀。

**互动**：地上掉落了面具。你可以捡起它（这是重要收集品）。

**结束**：魅影消失在一扇暗门后。一道光从门缝里透出来——通往歌剧院上方。

### 6.2 收集品

| # | 名称 | 位置 | 内容 |
|---|------|------|------|
| 1 | 《唐璜的胜利》手稿 | 管风琴乐谱架上 | 一部未完成的歌剧，最后一页空白 |
| 2 | 魅影的日记 | 桌上（蜡烛旁） | 记述童年被父母遗弃、被马戏团展览的经历 |
| 3 | 掉落的面具 | 揭面后地面 | 白色瓷质半面具——摸上去还是温热的 |

### 6.3 技术实现

**管风琴演奏**：
- 管风琴是场景中最大的元素（占画面宽度 40%）
- 琴键动画：按音乐节拍高亮对应位置的琴键（白/黑交替闪烁）
- 可交互：点击琴键发出对应音符（Tone.js `Synth.triggerAttackRelease`）

**蜡烛波浪点燃**：
- 从管风琴位置向外扩散，像水波纹
- `distance = Math.sqrt((candle.x - organ.x)² + (candle.y - organ.y)²)`
- 延迟 = distance × 0.02 秒
- 50-80 根蜡烛，总耗时约 3 秒

**揭面效果**：
- 全屏闪白 0.1 秒 → 全黑 1.5 秒（期间只有吼叫音效）
- 蜡烛重新点亮但色调变化：`hue-rotate` 从暖色 → 冷色（canvas `filter` 或手动调色）
- 面具掉落：从人物位置抛物线下落 + 弹跳 2 次 + 旋转，最终静止在地面

**音乐**：
- 《Music of the Night》完整播放（Tone.js 合成或预录 3-4 分钟）
- 揭面时：音乐突然切断（`Tone.Transport.stop()`）
- 吼叫音效：低频噪声 + 短混响
- 蜡烛重新亮起后：同一旋律但用小调/不协和版本，tempo 变慢

## 七、第四幕：All I Ask of You

> **核心曲目**：All I Ask of You + Reprise  
> **场景**：歌剧院屋顶  
> **时长**：8-10 分钟  
> **情绪线**：温柔 → 浪漫 → 心碎 → 愤怒

### 7.1 剧情

**开场**：你从暗门出来，站在歌剧院屋顶。巴黎夜景铺展在眼前——远处的灯火、月光、星空。空气清冷。

**第一段（告白）**：克里斯汀（金色光点）和拉乌尔（银色光点）站在屋顶边缘。她在说刚才地下发生的事，她很害怕。

**《All I Ask of You》响起。** 拉乌尔向她承诺保护她。二重唱——全剧最温柔的时刻。随着歌声，屋顶开始飘落白色花瓣。灯光变暖变柔。

**互动**：你可以探索屋顶——天使雕像、石兽装饰、远处的巴黎全景。在一个角落找到拉乌尔带来的花束。

**第二段（魅影偷听）**：但你注意到——屋顶另一侧，一个天使雕像的阴影里，**魅影一动不动地站着**。他听着这一切。

拉乌尔和克里斯汀拥抱着走下屋顶。

**第三段（Reprise — 魅影的愤怒）**：他们离开后，魅影独自走出阴影。

**《All I Ask of You (Reprise)》响起。** 同样的旋律，但变成了愤怒和绝望。天空开始闪电。花瓣变成了灰烬。灯光从暖色变成冷蓝色。

他唱到最后——*"You will curse the day you did not do all that the Phantom asked of you!"* ——一道闪电劈中天使雕像，雕像的翅膀碎裂。

魅影消失在黑暗中。

### 7.2 收集品

| # | 名称 | 位置 | 内容 |
|---|------|------|------|
| 1 | 拉乌尔的花束 | 屋顶角落 | 白玫瑰花束，丝带上绣着 C 的首字母 |
| 2 | 克里斯汀的围巾 | 栏杆上 | 演出后遗留，上面还有她香水的味道 |
| 3 | 天使雕像上的刻痕 | 雕像底座 | 魅影刻的字："我在这里聆听。永远。" |

### 7.3 技术实现

**巴黎夜景**：
- 远景层：深蓝色天空 + 星星（随机亮度闪烁的白色小点）+ 月亮（带光晕的渐变圆）
- 中景层：巴黎建筑轮廓（深色剪影）+ 窗户灯光（橙色小方块，随机闪烁）
- 近景层：屋顶地面、栏杆、天使雕像

**飘落花瓣**：
- 30-50 个白色粒子，从屏幕上方随机位置生成
- 运动：`y += 0.5`，`x += sin(time + offset) * 0.3`，轻微旋转
- Reprise 时：颜色渐变 白→灰→深灰，模拟花瓣变灰烬

**闪电**：
- 全屏白色闪光：`globalAlpha` 0 → 0.8 → 0（0.15 秒）
- 天空背景色瞬间变亮
- 雷声音效：短脉冲白噪声 + 低频衰减
- 雕像碎裂：翅膀部分替换为碎片 sprite + 碎片下落动画

**音乐**：
- 《All I Ask of You》：温暖的弦乐 + 钢琴二重唱（约 3 分钟）
- 过渡：音乐渐弱，短暂沉默
- 《Reprise》：同旋律但转小调，加入定音鼓、铜管，tempo 加快，力度渐强
- 闪电同步：闪电在 Reprise 最后一个高音时触发

## 八、第五幕：The Point of No Return + 终章

> **核心曲目**：The Point of No Return  
> **场景**：剧场（演出）→ 地下湖（最终对峙）→ 结局  
> **时长**：12-15 分钟  
> **情绪线**：紧张 → 危险 → 悲伤 → 释然

### 8.1 剧情

**开场**：你回到第一幕的剧场。但这次完全不同——灯火通明，座无虚席（观众幽影坐满了）。舞台上正在演出《唐璜的胜利》——你在第三幕看到过的那份手稿。

**第一段（演出 / 伪装）**：舞台上的两个身影在对唱。但"唐璜"的声音不对劲——太好了，太有力了。

**《The Point of No Return》响起。** 魅影伪装成演员在台上和克里斯汀对唱。气氛从暧昧变得危险。你能感觉到他不是在演戏——他是在对她倾诉真心。

**互动**：你在观众席中可以看到经理们在低声交流，他们也意识到了什么不对。

**第二段（揭面 + 水晶灯坠落）**：歌曲最后，克里斯汀在台上伸手揭下"唐璜"的面具——在所有观众面前。

魅影暴怒。

**水晶大吊灯的锁链断裂。**

- 巨大的碰撞声
- 屏幕剧烈抖动
- 碎片粒子爆炸（水晶碎片向四面八方飞溅）
- 观众幽影四散尖叫

黑暗中，魅影抓住克里斯汀，消失在舞台的暗门里。

**第三段（地下湖 — 最终对峙）**：你追下去。场景切换到地下湖的密室。

魅影用绳索威胁拉乌尔的生命，逼克里斯汀留下。三个人的剪影在烛光中对峙。紧张的音乐。

**克里斯汀缓缓走向魅影——亲吻了他。**

一切安静了。

音乐变成了温柔的钢琴独奏。魅影松开了绳索。他把一个音乐盒递给克里斯汀。光点人形的他，轮廓第一次变得柔和。

他让他们离开。

**第四段（告别）**：克里斯汀和拉乌尔的光点身影消失在湖面的雾中。密室里只剩魅影一个人。

他坐回管风琴前，弹了最后几个音。然后他拿起斗篷，盖住管风琴。吹灭了最后一根蜡烛。

**完全的黑暗。**

**第五段（尾声）**：一束光照亮了地面。那里只剩一样东西：

**他的面具。**

你走过去，点击面具。

黑屏。金色的字慢慢出现——

> *"他的音乐永远回荡在这座歌剧院里。"*

**片尾字幕。** 伴随着《Music of the Night》的钢琴独奏版缓缓滚动。

### 8.2 区域地图

```
剧场（演出）→ [舞台暗门] → 地下湖密室 → 结局画面
```

### 8.3 收集品

| # | 名称 | 位置 | 内容 |
|---|------|------|------|
| 1 | 《唐璜的胜利》节目单 | 观众席座椅上 | 今晚的节目单——"唐璜"一角的演员名字被涂掉了 |
| 2 | 魅影的音乐盒 | 密室（克里斯汀离开后掉落） | 旋转时播放一段小小的旋律 |
| 3 | 魅影的面具 | 最终场景地面 | 唯一的实体道具——全游戏的最后一件收集品 |

### 8.4 技术实现

**水晶灯坠落**（2D 版本）：
- 水晶灯 sprite 在画面顶部中央
- 坠落动画：`y` 加速下落（重力公式 `y += velocity; velocity += 0.5`）
- 到达舞台高度时：
  - 白色闪光全屏 0.1 秒
  - 50-80 个碎片粒子从碰撞点向四面八方飞散（随机角度、随机速度、重力衰减）
  - 灰尘粒子（低透明度大圆形）向上扩散
  - 屏幕抖动：`translate(random(-8,8), random(-8,8))` 衰减 1 秒
- 音效：金属断裂 → 坠落风声 → 碰撞声 → 碎裂声（叠加播放）

**亲吻场景**：
- 两个粒子人形缓缓靠近
- 接触瞬间：两个人的粒子颜色开始融合（暗色+金色 → 共同的暖白色）
- 周围蜡烛的火焰同时变大变亮
- 音乐从紧张转为温柔钢琴

**最终面具**：
- 全黑场景，一束光从上方照下（锥形渐变）
- 面具在光束中央，缓慢旋转（每秒 5°）
- 周围有微弱的金色尘埃粒子
- 点击面具 → 面具停止旋转 → 缓慢升起 → 渐变到结语文字

**片尾**：
- 黑色背景 + 金色文字（`Playfair Display` 字体）
- 文字滚动（从底部到顶部，速度慢）
- 背景音乐：《Music of the Night》钢琴版 fade in → 播放 → fade out

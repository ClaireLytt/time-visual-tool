# TimeVisual

可视化你的每一天 — 一个开源的时间记录与可视化工具。

## 功能

- 添加时间记录（活动名称、时长、权重、分类）
- 每日时间占比环形图可视化
- 自动计算时间总和与加权时长
- 按日期浏览和管理记录
- 数据本地存储（localStorage）

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- date-fns

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
